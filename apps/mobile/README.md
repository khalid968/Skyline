# Skyline — Flutter client

## One-time local bootstrap

This directory contains the hand-authored Dart source layout (`lib/`), `pubspec.yaml`, and lint config, but **not** the platform runner directories (`android/`, `ios/`, `windows/`, `macos/`, `linux/`, `web/`) — those are generated by the Flutter SDK's project templates and weren't produced here because the Flutter SDK isn't installed in this environment.

Before running the app, generate the platform runners once, on a machine with the Flutter SDK installed, from this directory:

```
flutter create --platforms=android,ios,windows,macos,linux,web --org com.skyline --project-name skyline .
```

This will not overwrite `lib/`, `pubspec.yaml`, or `analysis_options.yaml` — it only fills in the missing platform folders. After that:

```
flutter pub get
flutter analyze
flutter run -d <device>
```

## Layout

See `lib/features/README.md` for the feature-first Clean Architecture convention used throughout. `lib/core/` holds cross-cutting concerns (theming, routing, DI wiring, error handling, constants); `lib/shared/` holds widgets/providers reused across features; `native/crypto_bridge/` will hold the generated `flutter_rust_bridge` bindings to `crypto-core` starting in Phase 5.
